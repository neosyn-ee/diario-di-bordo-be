## Prerequisites

Multiple tools are required (or deemed as useful at least):
- IntelliJ (https://www.jetbrains.com/idea/download/?section=windows) (recommended to facilitate the project usage, cleanup, compilation, run, update, etc)
- Database connection: Either (or both)
  - PostgreSQL (https://www.postgresql.org/download/);
    The following additional packages are installed using the tool "Stack Builder 4.2.2." (the sub-choices are identified with a slash)
    - "Categories/Add-ons, tools and utilities/pgBouncer v1.24.1-1"
    - "Categories/Database Drivers/psqlODBC (64 bit) v13.02.0000-1)"
    - "Categories/Database Server/PostgreSQL (64 bit) v18.0-2"
    - "Categories/Spatial Extension/PostGIS 3.6 Bundle for PostgreSQL 18 (64 bit) v3.6.0"
  - DBeaver (https://dbeaver.io/download/), a powerful tool for managing DB instances, connection and inspection)
- Draw.io (https://www.drawio.com/)
